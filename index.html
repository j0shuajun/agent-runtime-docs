Agent Runtime Docs

Agent Runtime는 다양한 서비스에 연결할 수 있는 범용 agent API입니다. 사용자 권한에 따라 RAG 검색 범위와 MCP tool, Skill, Agent 노출 범위를 정하고, 허용된 기능만 답변 생성에 활용합니다. Chat 안에서는 사용자에게 보이지 않는 thread별 /workspace를 사용해 초안이나 중간 분석을 파일로 정리할 수 있지만, 실제 답변은 기존처럼 채팅 본문으로 전달합니다.

전체 흐름​

Agent Runtime를 처음 사용하는 서비스에서는 보통 다음 순서로 준비합니다.

  1. /v1/models와 /v1/indices로 사용할 model과 index 값을 확인합니다.
  2. user_id, chat_id, x_request_id 생성 규칙을 서비스 안에 정해 둡니다.
  3. /v1/chat/completions를 streaming 또는 non-streaming 방식으로 호출하고, finish_reason과 HTTP error envelope를 transport 계약에 맞게 처리합니다.
  4. MCP/Skill/Agent는 직접 호출하지 않고, permission_groups와 index를 정확히 전달합니다.
  5. 운영 조회가 필요하면 /v1/runs에서 run_id를 찾고 detail/evidence API를 호출합니다.

같은 chat_id는 대화 checkpoint, HITL, /workspace를 이어 주고, 같은 user_id는 사용자별 장기 Memory와 과거 대화 소유권의 기준이 됩니다.
