Skills

Skill은 특정 작업 방식이나 검토 기준을 runtime에 제공하는 instruction bundle입니다. 사용자는 Skill을 직접 선택하지 않습니다. 대신 permission_groups를 정확히 전달해야 runtime이 사용자에게 허용된 Skill만 사용할 수 있습니다.

파일 구조​

Skill directory
assets/
  skills/
    evidence-review/
      SKILL.md

위 경로는 배포 담당자가 관리하는 실제 asset 위치입니다. Runtime에서는 현재 요청의 permission_groups로 필터링한 Skill만 Agent-visible /skills/<name>/SKILL.md에 read-only로 연결합니다. Agent가 /assets/...나 host 경로를 직접 읽는 구조가 아닙니다.

SKILL.md에는 frontmatter와 본문 instruction을 작성합니다.

SKILL.md
---
name: evidence-review
description: Review answer grounding against retrieved RAG evidence.
access:
  permission_groups:
    - ORG_PROCESS
---

Use this skill when a response depends on retrieved semiconductor process evidence.
Check whether the answer separates evidence-backed facts from inference.

ORG_PROCESS는 frontmatter 형식을 보여 주기 위한 예시입니다. 실제 Skill에는 운영 권한 정책에서 정한 그룹명을 사용합니다.

필드 기준​

필드의미
name생략하면 skill directory 이름을 사용합니다. 명시하면 directory 이름과 같아야 합니다.
description필수입니다. /v1/manifest의 capabilities.skills[].description에도 노출됩니다.
accesspermission group 기준으로 Skill 노출 범위를 제한합니다.
본문runtime이 skill을 사용할 때 읽는 실제 작업 지침입니다.

access가 없거나 access.permission_groups가 비어 있으면 public Skill입니다. 값이 있으면 request의 orch.rag_params.permission_groups와 하나라도 겹칠 때만 main agent와 허용된 subagent가 볼 수 있습니다.
