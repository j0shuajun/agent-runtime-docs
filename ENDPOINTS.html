Endpoints

Agent Runtime 사용자와 운영자가 endpoint별 요청/응답을 확인하는 문서입니다. 내부 구현을 보지 않아도 어떤 기능을 호출해야 하는지 빠르게 확인할 수 있습니다.

요청별 identity, 권한, index, UUID 생성 규칙은 Usage Guide를 먼저 확인합니다.

전체 API​

기능Endpoint용도
StatusGET /, GET /health, GET /metrics서버가 정상적으로 요청을 받을 수 있는지 확인합니다.
CatalogGET /v1/models, GET /v1/indiceschat 요청에 사용할 model id와 검색 index 목록을 확인합니다.
ChatPOST /v1/chat/completions사용자 질문을 보내고 streaming 또는 JSON 응답을 받습니다.
RouterGET /v1/manifest, POST /v1/probeservice 정보와 검색 evidence를 확인합니다.
SearchPOST /v1/search/*검증된 검색 요청을 RAG API로 전달합니다.
RunsPOST /v1/runs, GET /v1/runs/{run_id}, GET /v1/runs/{run_id}/evidence실행 이력, main/subagent 중첩 순서, observation 입출력을 조회합니다.
API Key Management/internal/v1/api-keysSub Frontend·개인 Chat Key를 발급·조회·만료 갱신·폐기합니다.
